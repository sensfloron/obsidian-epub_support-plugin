## 实现方案：阅读页面跳转记忆 + 浏览器同款回退/前进快捷键

### 一、新增模块：`src/view/navigation_history.ts`

封装浏览器风格的双栈导航历史（`backStack` + `forwardStack`），纯逻辑、无 DOM 依赖、可测试。

```typescript
export interface ReadingLocation {
  chapterIndex: number;       // 当前章节（TITLEPAGE_INDEX 用 -1）
  pageIndex: number;          // 章节内页码
  showingTitlePage: boolean;  // 是否在扉页
}

export class NavigationHistory {
  private backStack: ReadingLocation[] = [];
  private forwardStack: ReadingLocation[] = [];
  private lastPushed: ReadingLocation | null = null;  // 去重基线

  /** 大跳转前调用：把 current 压入 backStack，清空 forwardStack（新分支） */
  push(current: ReadingLocation): void;

  /** 回退：返回目标 Location 或 null（栈空）。同时维护两栈。 */
  back(current: ReadingLocation): ReadingLocation | null;

  /** 前进：同上反向。 */
  forward(current: ReadingLocation): ReadingLocation | null;

  canGoBack(): boolean;
  canGoForward(): boolean;
  clear(): void;
}
```

去重规则：`push()` 时若 `current` 与 `lastPushed` 相等（chapter+page+titlePage 全等）则跳过，避免点击当前章节条目时产生空记录。

### 二、修改 `src/view/epub_view.ts`

#### 1. 新增字段
```typescript
private navHistory = new NavigationHistory();
private isRestoringHistory = false;  // 抑制历史回退/前进过程中的二次入栈
```

#### 2. 大跳转入栈：`pushHistorySnapshot()`
在 `navigateToChapter()` / `navigateChapter()` / `showTitlePage()` / `hideTitlePage()` 这四个大跳转方法的**入口处**调用，捕获"跳转前"的当前位置：
```typescript
private pushHistorySnapshot(): void {
  if (this.isRestoringHistory) return;          // 历史回退本身不再入栈
  const loc: ReadingLocation = {
    chapterIndex: this.showingTitlePage ? TITLEPAGE_INDEX : this.currentChapter,
    pageIndex: this.paginator?.getPageInfo().current ?? 0,
    showingTitlePage: this.showingTitlePage,
  };
  this.navHistory.push(loc);
}
```

逐页翻页（`paginator.navigatePage`）不经过这些方法 → 自然不入栈。

#### 3. 回退/前进执行：`goBack()` / `goForward()`
```typescript
private goBack(): void {
  const current = this.currentLocation();
  const target = this.navHistory.back(current);
  if (target) this.restoreLocation(target);
}
```

`restoreLocation(loc)` 复用现有的跳转路径：根据 `loc.showingTitlePage` / `loc.chapterIndex` 调用对应方法，并在 `isRestoringHistory=true` 包裹下执行，跳转完成后用 `paginator.goToPage(loc.pageIndex)` 恢复页码。

#### 4. 键盘绑定（修改 `registerKeyboard()`）
在现有 keydown 处理器开头加 Alt 分支，EPUB 视图激活时拦截：
```typescript
if (evt.altKey && !evt.ctrlKey && !evt.metaKey && !evt.shiftKey) {
  if (evt.key === 'ArrowLeft')  { evt.preventDefault(); this.goBack();  return; }
  if (evt.key === 'ArrowRight') { evt.preventDefault(); this.goForward(); return; }
}
```
（原有 ArrowLeft/ArrowRight 翻页逻辑不受影响，因为它们不带 Alt。）

#### 5. 鼠标侧键绑定（`onLoadFile` 末尾）
```typescript
this.registerDomEvent(this.contentEl, 'mousedown', (evt: MouseEvent) => {
  if (evt.button === 3) {            // X1 = 后退
    if (this.navHistory.canGoBack()) { evt.preventDefault(); this.goBack(); }
    // 栈空时放行 → Electron 默认 back 兜底
  } else if (evt.button === 4) {     // X2 = 前进
    if (this.navHistory.canGoForward()) { evt.preventDefault(); this.goForward(); }
  }
});
```

### 五、影响范围
- **新增**：1 个模块文件 + 1 个测试文件
- **修改**：`epub_view.ts`（约 +60 行，集中在大跳转方法入口和输入绑定）
- **不改动**：paginator、footnote、outline、progress 等模块

### 六、不会做的事
- 不持久化历史（用户已选"仅当前会话"）
- 不为滚动模式单独实现（滚动模式无分页器，pageIndex 概念不存在；回退仅恢复到章节级，通过现有 `scrollToChapter` 即可。若用户主要用分页模式，此限制可接受）
- 不修改 Obsidian 全局快捷键
