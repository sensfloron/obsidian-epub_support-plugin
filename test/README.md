# 🧪 EPUB 语法高亮测试使用指南

## 📖 概述

这是一套完整的测试工具，用于验证 EPUB 插件的语法高亮功能。包含手动测试文件和自动化测试脚本。

## 🚀 快速开始

### 方法一：手动测试（推荐）

1. **打开测试文件**
   - 在 Obsidian 中打开 `test/syntax_highlighting_test.md`
   - 这个文件包含了各种语言的测试用例

2. **打开开发者工具**
   - 按 `F12` 或右键点击 → "检查"
   - 切换到 "Console" 标签页

3. **查看日志输出**
   - 打开包含代码块的 EPUB 文件
   - 观察 Console 中的语法高亮日志
   - 检查语言检测是否正确

### 方法二：自动化测试

1. **准备测试环境**
   - 在 Obsidian 中打开任意 EPUB 文件（包含代码块）
   - 按 `F12` 打开开发者工具

2. **运行测试脚本**
   - 打开 `test/test_runner.js` 文件
   - 复制整个文件内容
   - 粘贴到浏览器 Console 中
   - 按 `Enter` 执行

3. **查看测试结果**
   - 测试会自动运行并显示结果
   - 结果会保存到 `window.epubTestReport`

## 🐛 常见问题排查

### 问题1: 所有代码块都显示 "❌ 未能提取渲染结果"

**可能原因:**
- MarkdownRenderer 的 DOM 结构与预期不符
- 选择器 `.markdown-rendered pre` 不正确

**解决方法:**
1. 查看 Console 中的 `wrapper.innerHTML` 输出
2. 检查实际的 DOM 结构
3. 调整选择器以匹配实际结构

### 问题2: 语言检测不准确

**可能原因:**
- 正则表达式模式不够准确
- 相似语言间的区分逻辑有问题

**解决方法:**
1. 记录检测错误的代码示例
2. 分析错误检测的语言特征
3. 调整 `detectLanguage()` 函数中的模式

### 问题3: 某些语言没有语法高亮

**可能原因:**
- Obsidian 的 Prism.js 不支持该语言
- 语言标识符不正确

**解决方法:**
1. 检查 Obsidian 支持的语言列表
2. 确认语言标识符拼写正确
3. 考虑使用通用 `text` 标识符

## 📈 性能基准

### 预期性能指标

- **单个代码块处理时间**: < 100ms
- **41个代码块总处理时间**: < 3秒
- **内存占用增长**: < 50MB
- **UI 响应时间**: < 200ms

### 性能优化建议

1. **批量处理**: 将多个代码块合并处理
2. **懒加载**: 只处理可见区域的代码块
3. **缓存机制**: 缓存已检测的语言结果
4. **Web Worker**: 将语言检测移到后台线程
